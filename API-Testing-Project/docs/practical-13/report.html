Problem Statement :
  • Integrate an AI API (Google Gemini REST API / OpenAI) into the existing full-stack Task Management application.
  • Securely manage external AI credentials on the server using environment variables (.env) without leaking keys to the client.
  • Implement the backend endpoint POST /api/ai/generate-description with request payload validation and custom in-memory rate limiting.
  • Design and integrate a responsive frontend UI feature with a 1-click ✨ Generate description with AI button, real-time loading state, and editable content field.
  • Implement comprehensive error handling demonstrating user feedback for cooldown rate limits (HTTP 429) and invalid or missing API configurations (HTTP 503).
  • Verify functionality through automated integration tests with Jest and Supertest, ensuring all test suites pass cleanly.

The frontend is augmented with a modal component (TaskModal.jsx) and full-page form (TaskForm.jsx) allowing users to enter a task title and instantly trigger the generative AI service.
